MeshCore Weather Station Gateway

Flash the firmware directly from your browser -- no build tools required.

Your browser doesn't support Web Serial. Please use a desktop build of Chrome or Edge (not available on mobile, Firefox, or Safari).

1. Connect your board

Plug in your Seeed XIAO ESP32-S3 (with Wio-SX1262 and CC1101 wired up per the hardware guide) via USB.

2. Flash

This erases the board and installs the latest weather-station gateway firmware. Your node identity/config will be reset.

3. After flashing

  • Open a serial terminal (115200 baud) to see boot/decode logs.
  • Connect with any MeshCore client to query telemetry, or send !weather in the configured group channel.
  • Default admin password is password -- change it via the CLI (set password ...) before deploying.
